Solaris FZ-500 — Pi 5 Assembly & Wiring

Step-by-step guide: from parts on the desk to running sensors. Standalone Pi 5, separate from Helios.

SAFETY FIRST: The vaporizer block runs at 200°C, the cartridge heater pulls 300W at 120V mains. Always wire the thermal fuse (240°C) in series with the cartridge heater. Use a GFCI outlet. Never run the heater without water in the drip well — the thermal fuse is your last line of defense.

Phase 1 — Pi 5 Setup

1CanaKit heatsink + fan

Apply a thin line of MX-6 thermal paste to the Pi 5's CPU (the big silver chip in the center). Press the CanaKit heatsink onto it — it has spring-loaded push pins that click into the board's mounting holes. Plug the fan header into the Pi 5's 4-pin fan connector (top edge of the board, between the USB-C power and the first USB-A).

2MicroSD card — flash Raspberry Pi OS Lite (64-bit)

Use Raspberry Pi Imager on your laptop. Choose "Raspberry Pi OS Lite (64-bit)" — no desktop needed, this is a headless sensor box. In the settings gear:

  • Hostname: solaris
  • User: fuze / password: Fuze47101 (matches your hotspot pattern)
  • WiFi: ISEEYOU2 / Fuze47101 (home) — add FX4 / Jetflow101 later
  • SSH: Enable with password auth
  • Locale: America/Denver, US keyboard

Flash it, insert the card into the Pi 5.

3Power on, find IP, SSH in

# From your laptop on the same network:
ssh fuze@solaris.local
# If mDNS doesn't resolve, check your router's client list for "solaris"

# First boot — update and install dependencies:
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3-pip python3-venv git i2c-tools

# Enable SPI and I2C:
sudo raspi-config nonint do_spi 0
sudo raspi-config nonint do_i2c 0
sudo reboot

4Python environment

# After reboot, SSH back in:
cd ~
python3 -m venv solaris-env
source solaris-env/bin/activate

pip install spidev smbus2 requests adafruit-circuitpython-sht4x adafruit-circuitpython-mlx90640

Phase 2 — Wiring

Pi 5 GPIO is 3.3V logic, same pinout as Pi 4. The MAX31855 breakouts run on 3.3V. The SHT41 QWIIC boards are 3.3V native. Everything is voltage-compatible — no level shifters needed.

I²C addresses (no conflict): SHT41 = 0x44, MLX90640 = 0x33. Both on I2C-1, no address collision. After wiring, verify with i2cdetect -y 1 — you should see both devices.

Visual Wiring Summary

The PID + SSR is a self-contained loop. The Inkbird ITC-100VH has its own K-type TC probe stuck in the vaporizer block. It reads the block temp and switches the SSR to bang the cartridge heater on/off. The Pi does NOT control the heater — it just reads the two thermocouples on the heat plate above. This is safer: even if the Pi crashes, the PID keeps the vaporizer at 200°C and the thermal fuse protects against runaway.

Phase 3 — Physical Assembly Sequence

1Mount vaporizer block to base plate

The stainless steel fixture has the base plate with the ~5" circular opening. The aluminum vaporizer block sits at the bottom of the 3" aluminum post. The cartridge heater slides into the blind bore in the vaporizer block — slip fit. Insert the PID's K-type TC probe into the 1/8" hole on the opposite side, pack with MX-6 thermal paste. The thermal fuse (240°C) wires in series between one leg of the cartridge heater and the SSR output — crimp or solder, then heat-shrink.

2Route water drip line

Cut ~3 feet of PTFE tubing (1/8" OD). Thread it down through the top of the aluminum post, all the way to the vaporizer block's drip well at the bottom. The top end exits the post and runs to the peristaltic pump output. The pump input connects to the DI water reservoir with another length of silicone tubing. Secure with hose clamps at both pump barbs.

3Install heat plate + thermocouple pads

The black-anodized 175×175mm aluminum heat plate sits on top of the post assembly, resting on the PC tray or directly on the stainless bracket. Bond TC-A and TC-B to the underside of the heat plate at opposite quadrants (50mm+ apart). Use MX-6 thermal paste in a small drilled well or tape them with high-temp Kapton tape and a dab of MX-6. Route the TC wires out through the PC tray wire channels.

4Wire MAX31855 breakouts to thermocouples

Each MAX31855 breakout has screw terminals for the thermocouple leads (+ and −). K-type polarity: yellow wire = (+), red wire = (−) — yes, red is negative on K-type, that's not a typo. Connect TC-A to MAX31855 #1, TC-B to MAX31855 #2. Then wire both breakouts to the Pi GPIO per the pin table above. Both share SCLK and MISO, but each gets its own CS line (CE0 vs CE1).

K-type polarity gotcha: Yellow = positive, Red = negative. This is backwards from what you'd expect. If you get it reversed, the MAX31855 will still read temperature — but it'll show decreasing values when the plate heats up. If your readings go down when the lamp is on, swap the leads at the screw terminal.

5Mount SHT41 in the air gap

The SHT41 goes on a small standoff in the 45mm air gap between the fabric and the heat plate. Use a 3D-printed bracket or just zip-tie it to a piece of wire bent into an L-shape, positioned centrally under where the fabric will be. Connect via the QWIIC/Stemma QT cable — it daisy-chains: Pi I²C header → SHT41 → MLX90640 (if installed). Run the cable out the side of the tray.

6Mount MLX90640 (optional)

The thermal camera looks down at the heat plate from just below the fabric plane. Mount it pointing downward, ~80-100mm above the plate, angled so the 32×24 pixel array covers the plate surface. Its 110° FOV at 100mm covers roughly 220×220mm — plenty for the 175mm plate. Same I²C bus as the SHT41, different address (0x33 vs 0x44).

7Wire pump circuit

The peristaltic pump is 12V. The Pi's GPIO is 3.3V. You need a switching transistor or MOSFET between them:

  • MOSFET gate → 1kΩ resistor → GPIO 12 (Pin 32)
  • MOSFET drain → Pump (−) terminal
  • MOSFET source → 12V PSU ground
  • Pump (+) → 12V PSU (+)
  • Flyback diode (1N4007) across the pump terminals — cathode (stripe) to pump (+), anode to pump (−). This absorbs the inductive kick when the motor switches off.
  • 10kΩ pull-down resistor from gate to ground (keeps pump off during Pi boot)

If you don't have a MOSFET handy, you can run the pump continuously (just plug it into 12V) for initial testing. PWM control is nice-to-have for adjusting flow rate, but the INTLLAB has its own manual speed knob.

8Wire PID + SSR (standalone loop, not Pi-connected)

This is a separate mains-voltage circuit — completely independent from the Pi:

  • Inkbird ITC-100VH: TC input ← PID K-type probe (in vaporizer block), relay output → SSR control (3-32V DC)
  • SSR-40DA: DC input (pins 3+4) ← PID relay output, AC output (pins 1+2) ← 120V mains in series with cartridge heater
  • Thermal fuse (240°C, 10A): wire in series between one AC leg and the cartridge heater
  • Mount SSR on finned heatsink — it'll dissipate ~3W when switching 300W
  • Set PID: SV=200°C, alarm=220°C

9Embroidery hoop + lamp mount

The 6" (150mm) embroidery hoop clamps the test fabric. Position it 45mm above the heat plate (use spacers or the stainless fixture's built-in shelf). The IR lamp mounts 200mm above the fabric plane in the ceramic socket/reflector housing. The stainless fixture's column should position this correctly — measure from the fabric surface to the bulb center.

Phase 4 — Verify Wiring

10Smoke test — check all sensors before powering the heater

# SSH into the Pi
ssh fuze@solaris.local
source ~/solaris-env/bin/activate

# Check I2C devices:
i2cdetect -y 1
# Expected: 0x33 (MLX90640) and 0x44 (SHT41)
# If MLX not installed, just 0x44

# Check SPI devices exist:
ls /dev/spidev0.*
# Expected: /dev/spidev0.0  /dev/spidev0.1

# Quick SHT41 read:
python3 -c "
import board, adafruit_sht4x
sht = adafruit_sht4x.SHT4x(board.I2C())
t, h = sht.measurements
print(f'Air temp: {t:.1f}°C  Humidity: {h:.1f}%')
"

# Quick MAX31855 read (raw SPI):
python3 -c "
import spidev
spi = spidev.SpiDev()
for cs in [0, 1]:
    spi.open(0, cs)
    spi.max_speed_hz = 5000000
    raw = spi.readbytes(4)
    val = (raw[0] << 24 | raw[1] << 16 | raw[2] << 8 | raw[3])
    if val & 0x7:
        print(f'TC on CE{cs}: FAULT (check wiring) — code {val & 0x7}')
    else:
        tc_c = ((val >> 18) & 0x3FFF)
        if tc_c & 0x2000: tc_c -= 16384
        tc_c *= 0.25
        print(f'TC on CE{cs}: {tc_c:.2f}°C')
    spi.close()
"

Both TCs should read room temperature (~20-25°C). The SHT41 should read ambient temp and ~30-50% humidity. If a MAX31855 returns a fault code: 1=open circuit (TC not connected), 2=short to GND, 4=short to VCC.

Phase 5 — Solaris Daemon

Here's the Python daemon that reads all sensors at 1 Hz and POSTs to FUZE Atlas. Save as ~/solaris_daemon.py:

#!/usr/bin/env python3
"""
Solaris FZ-500 — Sensor Daemon
Reads 2× MAX31855 (SPI), SHT41 (I²C), optional MLX90640 (I²C)
POSTs time-series to FUZE Atlas /api/admin/solaris-tests/[id]/ingest
"""

import time, json, sys, os, signal
import spidev
import board
import adafruit_sht4x
import requests

# ── Config ──────────────────────────────────────────────
ATLAS_BASE    = os.environ.get("ATLAS_URL", "https://atlas.fuze47.com")
TEST_ID       = os.environ.get("SOLARIS_TEST_ID", "")
BEARER_TOKEN  = os.environ.get("ATLAS_TOKEN", "")
SAMPLE_HZ     = 1          # 1 sample per second
RUN_DURATION  = 600        # 10 minutes = 600 seconds
BUFFER_SIZE   = 60         # POST every 60 samples (1 min)
# ────────────────────────────────────────────────────────

# ── SPI: MAX31855 ×2 ───────────────────────────────────
def read_max31855(bus, cs):
    """Read temperature from MAX31855 on SPI bus/cs. Returns (temp_c, fault)."""
    spi = spidev.SpiDev()
    spi.open(bus, cs)
    spi.max_speed_hz = 5_000_000
    spi.mode = 0
    raw = spi.readbytes(4)
    spi.close()

    val = (raw[0] << 24 | raw[1] << 16 | raw[2] << 8 | raw[3])
    fault = val & 0x7
    if fault:
        return None, fault

    tc_raw = (val >> 18) & 0x3FFF
    if tc_raw & 0x2000:
        tc_raw -= 16384
    return tc_raw * 0.25, 0

# ── I²C: SHT41 ─────────────────────────────────────────
i2c = board.I2C()
sht = adafruit_sht4x.SHT4x(i2c)
sht.mode = adafruit_sht4x.Mode.NOHEAT_HIGHPREC

# ── Optional: MLX90640 ──────────────────────────────────
mlx = None
try:
    import adafruit_mlx90640
    mlx = adafruit_mlx90640.MLX90640(i2c)
    mlx.refresh_rate = adafruit_mlx90640.RefreshRate.REFRESH_2_HZ
    print("[OK] MLX90640 thermal camera detected")
except Exception:
    print("[--] MLX90640 not found — running without thermal camera")

# ── Graceful shutdown ───────────────────────────────────
running = True
def handle_signal(sig, frame):
    global running
    running = False
    print("\n[!!] Shutting down...")
signal.signal(signal.SIGINT, handle_signal)
signal.signal(signal.SIGTERM, handle_signal)

# ── POST buffer to Atlas ────────────────────────────────
def post_to_atlas(samples):
    if not TEST_ID or not BEARER_TOKEN:
        return  # local-only mode
    url = f"{ATLAS_BASE}/api/admin/solaris-tests/{TEST_ID}/ingest"
    try:
        resp = requests.post(url, json={"samples": samples}, headers={
            "Authorization": f"Bearer {BEARER_TOKEN}",
            "Content-Type": "application/json"
        }, timeout=10)
        if resp.status_code == 200:
            print(f"  [POST] {len(samples)} samples → Atlas OK")
        else:
            print(f"  [POST] Atlas returned {resp.status_code}: {resp.text[:100]}")
    except Exception as e:
        print(f"  [POST] Failed: {e}")

# ── Main loop ───────────────────────────────────────────
def main():
    print("=" * 60)
    print("  SOLARIS FZ-500 — Sensor Daemon")
    print(f"  Duration: {RUN_DURATION}s @ {SAMPLE_HZ} Hz")
    print(f"  Atlas: {'CONNECTED' if TEST_ID else 'LOCAL ONLY (no TEST_ID)'}")
    print("=" * 60)

    buffer = []
    t_start = time.time()
    sample_n = 0

    while running and sample_n < RUN_DURATION * SAMPLE_HZ:
        t0 = time.time()
        elapsed = t0 - t_start

        # Read thermocouples
        tc_a, fault_a = read_max31855(0, 0)
        tc_b, fault_b = read_max31855(0, 1)

        # Read SHT41
        try:
            air_t, air_h = sht.measurements
        except Exception:
            air_t, air_h = None, None

        # Read MLX90640 (optional, slow — every 5th sample)
        thermal_frame = None
        if mlx and sample_n % 5 == 0:
            try:
                frame = [0] * 768
                mlx.getFrame(frame)
                thermal_frame = [round(p, 1) for p in frame]
            except Exception:
                pass

        sample = {
            "t": round(elapsed, 2),
            "n": sample_n,
            "tc_a": round(tc_a, 2) if tc_a is not None else None,
            "tc_b": round(tc_b, 2) if tc_b is not None else None,
            "tc_a_fault": fault_a if fault_a else None,
            "tc_b_fault": fault_b if fault_b else None,
            "air_temp_c": round(air_t, 2) if air_t is not None else None,
            "air_rh_pct": round(air_h, 1) if air_h is not None else None,
        }
        if thermal_frame:
            sample["thermal"] = thermal_frame

        buffer.append(sample)
        sample_n += 1

        # Console output
        tc_a_s = f"{tc_a:.1f}°C" if tc_a else f"FAULT:{fault_a}"
        tc_b_s = f"{tc_b:.1f}°C" if tc_b else f"FAULT:{fault_b}"
        air_s  = f"{air_t:.1f}°C/{air_h:.0f}%" if air_t else "ERR"
        pct = int(elapsed / RUN_DURATION * 100)
        print(f"  [{pct:3d}%] {elapsed:6.1f}s  TC-A={tc_a_s}  TC-B={tc_b_s}  Air={air_s}")

        # Flush buffer
        if len(buffer) >= BUFFER_SIZE:
            post_to_atlas(buffer)
            buffer = []

        # Maintain 1 Hz cadence
        dt = time.time() - t0
        if dt < 1.0 / SAMPLE_HZ:
            time.sleep(1.0 / SAMPLE_HZ - dt)

    # Final flush
    if buffer:
        post_to_atlas(buffer)

    print("\n" + "=" * 60)
    print("  RUN COMPLETE")
    print(f"  Total samples: {sample_n}")
    print(f"  Duration: {time.time() - t_start:.1f}s")
    print("=" * 60)

if __name__ == "__main__":
    main()

Systemd Service (auto-start on boot)

# Create the service file:
sudo tee /etc/systemd/system/solaris.service <<'EOF'
[Unit]
Description=Solaris FZ-500 Sensor Daemon
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=fuze
WorkingDirectory=/home/fuze
ExecStart=/home/fuze/solaris-env/bin/python3 /home/fuze/solaris_daemon.py
Restart=on-failure
RestartSec=10
Environment=ATLAS_URL=https://atlas.fuze47.com
Environment=SOLARIS_TEST_ID=
Environment=ATLAS_TOKEN=

[Install]
WantedBy=multi-user.target
EOF

# Enable but don't start yet (no test ID configured):
sudo systemctl daemon-reload
